from textwrap import dedent

from docx.shared import Pt

doc=Document()
doc.add_heading('Buzzard Power Suite\nSoftware Design Specification (SDS)\nVersion 0.3.0',1)

style=doc.styles["Normal"]

sections=[
("1. Purpose","Buzzard is a modular Linux power-management framework with a vendor abstraction layer. The goal is to provide a safe, extensible replacement for OEM utilities while remaining open source."),
("2. Objectives",
"""
Functional:
• Switch GPU profiles.
• Control CPU governors.
• Manage brightness, Bluetooth, TLP and optional PowerTOP.
• Diagnose system health.
• Restore previous profile.
• Profile history.
• Vendor-specific extensions.

Non-functional:
• Safe by default.
• Rollback support.
• Testable.
• Modular.
• Linux-first.
"""),
("3. High-Level Architecture",
"""
CLI -> Dispatcher -> Command -> Service -> Manager -> Shell -> Linux

Commands contain no business logic.
Services orchestrate workflows.
Managers interact with hardware.
Shell is the only subprocess layer.
"""),
